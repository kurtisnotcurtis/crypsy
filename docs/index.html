Built for Speed & Privacy

Everything You Love About Keep, Encrypted

Fast, tactile note-taking without surrendering your private thoughts to a remote database.

Transparent AES-256-GCM

Every note, spatial board, tag, and pasted WebP image is encrypted in-browser via the native WebCrypto API using PBKDF2-SHA256 (150,000 iterations) and authenticated AES-256-GCM.

OneNote-Style Spatial Boards

Click anywhere on a pannable, zoomable canvas to place text boxes, pasted screenshots, and link cards—with free move, resize, rotation, alignment, and live thumbnail previews.

Bring Your Own Cloud (BYOC)

Link any local folder synced by OneDrive, Google Drive, Dropbox, or iCloud Drive. Crypsy writes directly to vault.crypsy.json and polls for remote edits.

Instant Search & Context Menus

Press / or Ctrl+K to filter notes and boards with live highlighting, or right-click cards, sidebar tags, and board items for fast editing (Shift+Right-Click keeps native menus).

Tags, Pins & Color Palettes

Organize notes and boards with collapsible sidebar #tags, pin priority cards to the top, attach clipboard images or links, and customize with 7 Dark/Light themes.

Zero-Dependency Portable HTML

Bundle the entire application into a single self-contained Crypsy-Portable.html file that lives right next to your encrypted vault in your cloud drive.

How Bring Your Own Cloud Works

Set up encrypted multi-device sync in under 30 seconds using the browser onboarding wizard or the CLI installer.

1

Choose Your Cloud Drive

Open Crypsy and click "Setup Cloud Folder". Select OneDrive, Google Drive, Dropbox, iCloud Drive, or any custom synced folder.

2

Link & Provision Folder

Grant folder access via the browser File System Access API. Crypsy automatically provisions vault.crypsy.json and Crypsy-Portable.html inside your cloud folder.

3

Sync Across Every Device

Every edit is encrypted with AES-256-GCM and written to disk immediately. Your desktop cloud client handles syncing across all your machines.

Prefer a terminal installer? Auto-detects cloud folders on Windows, macOS & Linux: PowerShell / Bash / Node.js 
# Clone Crypsy Note
git clone https://github.com/kurtisnotcurtis/crypsy.git
cd crypsy

# Launch interactive cloud drive installer (Windows PowerShell or macOS/Linux)
.\install.ps1          # or ./install.sh

# Or build the standalone single-file Crypsy-Portable.html bundle
node install.js --build-only
